# QMind

Work with the QMind knowledge base: retrieve evidence, manage sources, and
organize files.

## Steps

1. **Retrieve** with a concise, keyword-rich query; cite the notebook/source.
2. **Browse** a notebook's sources when the user asks what is in it.
3. **Import** a file or an HTTPS link into the right directory.
4. **Organize**: create directories and move files to keep the base tidy.

## Notes

- Cite evidence with its source; never fabricate retrievals.
- Confirm before destructive moves/deletes of user content.
