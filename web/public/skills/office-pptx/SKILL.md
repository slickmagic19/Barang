# PowerPoint

Build and edit `.pptx` decks.

## Steps

1. **Plan the deck**: outline slides from the source material before writing.
2. **Create slides** with a consistent layout (title, body, image slots).
3. **Fill content** concisely — one idea per slide, speaker-friendly bullets.
4. **Style consistently**: shared theme, fonts, and spacing.
5. **Verify**: reopen the deck, check slide count and overflow.

## Notes

- Prefer editable text over baked-in images of text.
- Respect the template's placeholders when editing an existing deck.
